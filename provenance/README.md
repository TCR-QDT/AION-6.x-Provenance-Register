# Provenance Documentation

## Overview

This directory contains documentation about the provenance status of materials related to AION-6.x.

## Documents

### TCR_QDT_BRIDGE.md

Status of the material bridge between TCR/QDT repository (captured) and AION-6.x corpus source (not materially accessible).

### CORPUS_PROVENANCE.md

Per-CORPUS-ID provenance status. Tracks the verification of each expected corpus document against material candidates.

### HISTORICAL_STATUS.md

Historical status of AION-6.x components as declared in the AION-MVP-001 Handoff, with current recovery state.

## Epistemic principle

All documents in this directory follow the AION-7.0.0 epistemic principles:

- `UNAVAILABLE ≠ NON-EXISTENT`
- `NON-OBSERVED ≠ FALSE`
- `PENDING ≠ FAILED`
- `COMPATIBLE ≠ EQUIVALENT`

Material recovered after repository initialization is recorded with its **incorporation date**, distinct from the **historical event date** described in the document.
